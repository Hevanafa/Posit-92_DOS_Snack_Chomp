SNACKLINE (DOS)

A game by Hevanafa
Originally made for the Tribute to DOSBox game jam held
on itch.io in October 2026

Built with Turbo Pascal 7
Powered by Posit-92 (DOS)

Requirements:
- Any DOS x86 (at least 386)
- VGA graphics
- PC speaker for sound effects

Starting the game:
On Windows: run or double click start.bat
On DOS: run GAME.EXE

Controls:
- SPACE - close mouth
- ESC - exit game

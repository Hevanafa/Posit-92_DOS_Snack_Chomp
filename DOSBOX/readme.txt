SNACKLINE (DOS)

A game by Hevanafa
Originally made for the Tribute for DOSBox game jam held
on itch.io in October 2026

Built with Turbo Pascal 7
Powered by Posit-92 (DOS)

Requirements:
- Any DOS x86 (at least 386)
- VGA graphics
- PC speaker for sound effects

Run GAME.EXE to play

Controls:
- SPACE - close mouth
- ESC - exit game
